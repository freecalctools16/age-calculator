# Age Calculator

A modern and responsive Age Calculator built with HTML, CSS, and JavaScript.

This tool calculates a user's exact age instantly without requiring a Calculate button.

## Features

- Instant age calculation
- Years, months, and days
- Automatic updates
- Responsive design
- Modern UI
- Pure HTML, CSS, and JavaScript
- No external libraries
- Lightweight and fast

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How to Use

1. Open the calculator in your browser.
2. Select your date of birth.
3. View your age instantly.
